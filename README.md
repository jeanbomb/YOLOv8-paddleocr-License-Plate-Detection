# 車牌辨識系統 (YOLOv8-paddleocr-License-Plate-Detection)
[日本語](#日本語) | [中文](#中文)

---

## <a name="中文"></a>中文版

本專案在 Kaggle 上開發，利用 YOLOv8 進行車牌偵測，並結合 PaddleOCR 進行文字辨識，透過 OpenCV 進行影像處理，最後使用 Matplotlib 視覺化呈現結果。

### 📌 專案特色
- **YOLOv8 車牌偵測**：使用深度學習模型 YOLOv8 來準確偵測車牌位置。
- **OCR 文字辨識**：使用 PaddleOCR 支援中英文的高精度辨識工具。
- **OpenCV 影像處理**：色彩空間轉換、影像前處理優化。
- **Matplotlib 視覺化**：即時顯示偵測與辨識結果。

### 📊 目前進度
- ✅ YOLOv8 模型載入  
- ✅ PaddleOCR 整合  
- ✅ 批次處理功能  
- ❌ 效能優化待改進

## <a name="日本語"></a>日本語

本プロジェクトはKaggleで開発され、YOLOv8でナンバープレート検出を行い、PaddleOCRで文字認識を組み合わせています。OpenCVで画像処理を行い、最終的にMatplotlibで結果を可視化します。

### 📌 プロジェクト特徴
- **YOLOv8 ナンバープレート検出**：深層学習モデルYOLOv8で正確にナンバープレート位置を検出
- **OCR文字認識**：PaddleOCRで日本語・中国語に対応した高精度認識
- **OpenCV画像処理**：色空間変換・画像前処理の最適化
- **Matplotlib可視化**：検出・認識結果を即時表示
